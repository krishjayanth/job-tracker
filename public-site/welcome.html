How it works

          
From inbox to status in four steps.

        

        
    
          
  1. Narrow the inbox
    A Gmail search keeps only emails from hiring platforms or about applications. Nothing else is opened.
    2. 
          
  2. Understand each email
    Each match is read for the company, role, job ID and stage, then checked against rules.
    3. 
          
  3. Group into applications
    Emails join an application by thread, then company and job ID, then company and role.
    4. 
          
  4. Work out the status
    Status comes from the email timeline, so it's always the latest thing the company told you.

FAQ

          
Questions, answered.

        

        

          

            Can nuj send, delete or change my email?
            
No. It asks Google only for read-only access, which can't send, delete, label or change anything in your inbox.

          

          

            What does the AI see?
            
Only emails that match the application search. For each, the sender, date, subject and up to the first 3,000 characters of the message are sent to Groq to work out the company, role and stage. If Groq is unavailable, built-in rules handle it and nothing is sent.

          

          

            What if it gets an application wrong?
            
Fix it in the app: rename the company, change the status, add a deadline or delete it. Your changes are kept, even through a full re-scan of your inbox.

          

          

            Can I run my own copy?
            
Yes. The code is on GitHub. Run npm run demo to try it with sample data, no Google account needed.
